# Tutu Lab — loja

Loja das peças impressas em 3D do Tutu Lab. Site estático publicado no GitHub Pages.

- `loja.html` — página da loja. As listas `LOJA` (WhatsApp, Instagram) e `PECAS` (produtos) ficam no começo do script.
- `img/pecas/` — fotos das peças.
- `python montar-site.py` — gera o `index.html` publicado a partir de `loja.html`. Rode depois de cada mudança e faça commit dos dois.
